家庭保单检视 Skill V3.2

50 行核心代码 · 11 个测试用例 · 5 大 AI 助手兼容

零依赖 隐私优先 多币种 HTML 报告 MIT 许可

核心特性

  • 隐私脱敏（L4-L5 字段自动屏蔽：身份证、银行卡、手机号）
  • 险种智能分类（中英文：寿险/重疾险/医疗险/意外险/年金险）
  • 保障缺口诊断（寿险 + 重疾，缺口公式：保障需要 - 可用资产）
  • 冲突检测（医疗险重复 + 团险识别 + 质押贷款提示）
  • 多币种支持（CNY/HKD/USD/EUR，自动换算）
  • HTML 可视化报告

3 步快速开始

1. 准备数据

创建 policies.json 和 family.json：

// policies.json
[
  {"holder": "户主", "name": "平安寿险", "type": "寿险",
   "coverage": 1000000, "premium": 12000}
]

// family.json
{"members": ["户主", "配偶"], "annual_income": 500000,
 "debt": 2000000, "dependents": 1}

2. 安装到 AI 助手

./install.sh trae        # 仅安装到 TRAE
./install.sh claude      # 安装到 Claude Code
./install.sh opencode    # 安装到 OpenCode
./install.sh codex       # 安装到 Codex
./install.sh cursor      # 安装到 Cursor
./install.sh all         # 全部安装

3. 运行分析

python insurance_review.py
# 输出：report.html（可视化报告）

输入字段

字段必填默认说明
holder是-投保人（团险填公司名）
name是-产品名称
type否自动险种
coverage是-保额（数字）
premium是-年保费（数字）
currency否CNYCNY/HKD/USD/EUR
cash_value否0现金价值
